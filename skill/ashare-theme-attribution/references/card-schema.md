# 研究卡字段规则

研究卡是归因管线的**唯一产物**。它不是分析报告，是一份带时间戳、可回看、可证伪的判断记录。

设计前提：归因的产物是**研究队列**，不是交易信号。卡片必须走到「该事件是否构成真实现金流变化」的判定，据此决定是否交接给财报分析。停在「因为 XX 公告所以涨」等于建了个追涨工具。

---

## 标识字段

| 字段 | 类型 | 规则 |
|---|---|---|
| `card_id` | string | 默认 `{anomaly_date}_{theme}`，如 `2026-10-14_AI短剧`。同题材同日重复归因会覆盖，这是有意的——一天一张卡 |
| `theme` | string | **必须与 `vest anomalies` 输出的题材字符串完全一致**，否则后续无法用 `vest evidence` 复现证据包 |
| `anomaly_date` | date | 异动交易日 `YYYY-MM-DD` |
| `created_at` | timestamp | 入库时自动填 |

## `anomaly_detail`

异动的客观描述 + 当日大盘背景。

必填 `stock_count`、`avg_pct_chg`、`members`（每只含 `code`/`name`/`pct_chg`/`turnover_rate`）。

**强烈建议填 `market_context`**：当日指数涨跌、涨跌家数、成交额。逆势涨停与普涨行情中的涨停是完全不同的信号——缩量市场里资金在极窄题材内抱团，逆势涨停不需要基本面理由就能出现。缺了这一项，很容易把资金面现象误读成题材本身的强度。

`turnover_rate` 是判断资金性质的关键：15%-20% 的极高换手指向筹码剧烈交换（游资接力），而非机构建仓。

## `evidence`

**只放经过分桶的证据，且必须保留分桶归属。** 不要把四个桶揉成一个「相关证据」列表——那等于丢掉了整套机制的价值。

每条证据至少含：`ts`（原始时间戳）、`kind`（announcement/news）、`code`、`title`、`implication`（这条证据说明什么）。

建议额外记录两个元字段：

- `pre_session_缺失`：如果 pre_session 桶里**没有任何基本面催化类证据**（协议/订单/政策/业绩），必须显式写出来。「找不到原因」本身是最强的结论之一——它意味着这波行情没有可验证的基本面支撑。
- `post_close_已排除`：把那些看起来最像原因、但因发布于收盘后而被排除的证据单独列出，并写明 `reason_excluded`。**这是最容易出错的一步**：收盘后发布的利好往往是媒体对当日行情的解释性报道，它可能是次日行情的催化，但物理上不可能是当日涨幅的原因。

## `classification`

四分类，每类都必须存在（可以为空数组，但键要在）。

| 类 | 收录标准 |
|---|---|
| `事实` | 可在巨潮公告或行情数据中直接核验的客观陈述。例：「掌阅科技 10-14 涨停，换手 15.28%」「9-25 公告股东集中竞价减持计划」 |
| `推论` | 由事实推出、但本身未被直接观测的判断。例：「板块行情启动于 10-09，10-14 是资金接力的延续段」 |
| `观点` | 第三方主观判断，**每项必须带 `source`**。例：`{"source": "同花顺编辑部", "content": "题材标签「AI短剧/短剧出海」"}` |
| `待验证` | 现在无法确定的问题。例：「腾讯绿泡泡短剧的实际分账模式与上游制作方收益比例」 |

三条纪律：

1. **同花顺 `reason` 标签只能进「观点」**，不得进「事实」。它是编辑部人工运营的叙事框架，把它当事实会让整张卡继承别人的分类体系。
2. **不确定就放「待验证」**。不要为了让四个分类都非空而虚报确定性——真实的归因大多落在待验证。
3. **媒体对基本面的判断是「观点」，不是「事实」**。例：第一财经「AI变现存疑、业绩承压」是观点，但它是极有价值的反方证据，应当进 `counter_argument`。

## `counter_argument`

写**支持相反结论的最强论证**，不是把结论换个说法复述一遍。

自检：把这段单独拿出来给一个不了解你结论的人看，他能不能据此主张相反的判定？如果不能，这不是反方论证。

必须覆盖的检查项：

- 有没有同样成立但被忽略的解释？（单纯资金轮动、游资接力、指数被动买入、北向调仓）
- **成分股在股价启动前有没有股东减持计划、业绩预警、立案调查、问询函？** 产业资本的行为与二级市场情绪相反时，是极强的反方证据，必须点出。
- 被时间约束排除的那些诱人解释，如果放宽约束会不会成立？为什么仍然不采信？

## `falsifiable_check`

「若判定成立，接下来应观察到 X」。**X 必须可在巨潮公告或行情数据中被第三方验证。**

不合格示例：「继续关注后续走势」「留意资金动向」——这些无法证伪。

合格示例：「10-15 起换手率维持高位但股价滞涨或回落」「腾讯绿泡泡利好在 10-15 兑现为高开后走弱（利好出尽）」「连板梯队出现断板」「三季报中短剧相关收入占比 <5%」。

**同时写出反向条件**：若判定错误、实为基本面驱动，应当看到什么？（例：出现可在巨潮验证的正式合作协议公告，或财报中出现可辨认的短剧收入科目。）没有反向条件的证伪检验是不完整的。

## `fundamental_verdict`

取值限定四个，不得自创：

| 值 | 含义 | 后续动作 |
|---|---|---|
| `基本面变化` | 异动有可验证的现金流/业绩支撑 | 必填 `followup_queue`，交接财报分析 |
| `情绪资金驱动` | 无基本面催化，资金与情绪自我强化 | 仍可填 `followup_queue`——业务本身是否值钱是**独立问题**，不因这次涨停而追高 |
| `待验证` | 证据不足以下判定 | 必填 `followup_queue`，写明缺什么证据 |
| `噪声` | 无研究价值 | 可不填 `followup_queue` |

**注意**：判定为「情绪资金驱动」**不等于**标的没有研究价值。本次异动的归因结论与「这家公司值不值这个价」是两个问题。把它们混为一谈，就会因为一次题材涨停而跳过本该做的基本面功课。

## `followup_queue`

数组，每项含：

| 字段 | 说明 |
|---|---|
| `code` / `name` | 标的 |
| `question` | **具体到可执行**的问题。不合格：「分析一下财务状况」。合格：「AI短剧/数字阅读业务的实际收入占比与毛利率，是否与当前估值匹配」 |
| `trigger` | 何时能回答。如「三季报披露」「公告可读时」 |
| `note` | 可选，交接时的提醒 |

交接目标：`financial-statement-analysis`（财务状况与发展方向）或 `financial-report-minesweeper`（排雷）。交接时必须说明**本次异动归因结论不构成买入理由**。

## `review_at` / `review_note`

`review_at` = 异动日后第 5 个交易日（约 7 个自然日）。

到期时用 `vest review <card_id> "<实际结果>"` 回填。**这是判断账本的闭环**——不回填，卡片就只是当天情绪的快照，永远无法校准判断质量。

回填纪律：诚实记录判定错误的情况，不要为了好看而美化。一个全是「判定正确」的账本没有信息量。

---

## 硬性禁止

研究卡全文**不得出现**：仓位建议、买卖点、目标价、涨跌预测。

本管线是研究工具，不是信号生成器。
